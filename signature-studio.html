นำ Signature ไปใช้ใน Outlook

สำหรับ Classic Outlook สามารถดาวน์โหลด Installer เพื่อวางไฟล์และตั้งค่าเริ่มต้นอัตโนมัติได้ ส่วน New Outlook ใช้วิธีคัดลอกไปวางในหน้า Settings

  1. ถ้าใช้ Classic Outlook 2010 ขึ้นไป ให้กด Download Classic Outlook installer ในขั้นตอน Review
  2. เปิด PowerShell ในโฟลเดอร์ Downloads แล้วรันไฟล์ Installer ที่ดาวน์โหลด
  3. ถ้าใช้ New Outlook หรือ Outlook Web ให้กด Copy rendered signature
  4. เปิด Settings → Mail → Compose and reply หรือ Signatures แล้ววางด้วย Ctrl+V
