# Choose deployment and assets

Status: resolved
Type: decision
Map: outlook-signature-gui-map.md

## Question

How should the application and company assets be delivered to users, and how should logos/images be stored for reliable Outlook rendering?

Recommended starting point: portable per-user deployment first, no administrator rights, with local signature asset folders and a later MSI/central branding phase after the design is validated.

## Resolution

User selected the recommended portable per-user deployment and explicitly deferred Logo/image support for the first release.
