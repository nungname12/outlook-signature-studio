# Define Set Signature behavior

Status: resolved
Type: decision
Map: outlook-signature-gui-map.md

## Question

When the user clicks `Set Signature`, which defaults and files should be changed?

Recommended starting point: write the HTML/TXT signature package, back up same-name files, and set both New messages and Replies/forwards for the selected account/profile, with a clear confirmation result and no email sending.

## Resolution

User selected the recommended behavior: `Set Signature` writes the package, creates a backup, and sets both New messages and Replies/forwards without sending email.
